# 📜 Cordel Moderno | Modern Cordel

## 🇺🇸 English

Responsive website created to practice **HTML5 and CSS3**, using a poetry-based layout to explore typography, backgrounds, positioning, and responsive design.

### 🛠️ Technologies

* HTML5
* CSS3
* Git & GitHub
* GitHub Pages

### 💡 What I Practiced

* Semantic HTML
* Responsive design
* CSS backgrounds
* Background images
* Typography
* Page layout and positioning
* Media Queries

### 📚 Credits

Project developed as part of my studies based on the **HTML5 and CSS3 course by Gustavo Guanabara- Curso em Vídeo**.
